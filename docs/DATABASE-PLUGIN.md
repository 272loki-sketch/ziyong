# 原数据库插件接入（本地 v1.8.7）

## 采用方式

使用用户指定的 AlbusKen/shujuku `naiv1.2.4` 安装脚本，原样私有缓存，不fork或把无明确整体授权的上游产物复制进公开源码/发行包。固定SHA-256为 `ff8981ea9f60bbada765ce79d576bf84963e842c12b683feb6e8fe22b74b8bac`。已按Git blob核对CDN产物；来源名/版本、指纹与上游更新候选可在设置面板查看。

梨园只维护宿主适配：模型调用、当前分支聊天、metadata/settings、世界书、私有文件与生命周期。原人物表、纪要、填表解析、索引、交火BM25/向量融合、0TK和原管理台继续使用上游实现。插件的独立剧情代写/推演不作为第三种正文模式；direct/director与原作者卡格式不变。

## 事实和隐私边界

- `Session Tree/rpNarrative`仍是故事事实。只提供规范正文；作者原交付、thinking和工具回执不作为正文传给插件。
- 插件的消息扩展只允许 `TavernDB_*`，不允许写mes、rpNarrative或思考；会话＋卡作用域、sourceEntryId与revision/CAS保护迟到提交。读状态只取当前祖先来源，兄弟分支不可见。
- 插件生成的世界书是专用派生书。原卡/挂载书供读取，不允许插件改写生产PNG或复活关闭条目。0TK控制目录常驻，宿主只投送相关的条目，明确标注截断预算。
- `.liyuan-database-plugin/`0700、文件0600；包括状态、设置、向量、上游缓存与私有依赖，不入Git/发行包。外置对象使用内容寻址blob与来源指针，读取只查祖先来源，分支删除用tombstone，不删除其他分支仍引用的对象。API Key沿用服务端记忆岗位和独立嵌入配置，不通过宿主context返回真实Key；上游存量设置里的嵌套/JSON字符串密钥和URL查询凭据下发时掩码，掩码回写保留服务端原值。
- 普通配置后台角色仍按原岗位解析，不统一换GPT；自定义向量/重排仅代理已保存HTTPS连接，拒绝私网/回环及任意地址。

## 时序与恢复

启用插件时旧自动周期正文入库、旧事件提取、旧摘要压缩关闭，但旧SQLite和摘要原文不删除。作者保留最近有界正文，长期资料由原插件提供；旧分支已有摘要仍作为只读迁移资料保留，不继续运行旧摘要模型，也不默默抹掉旧会话的重要前情。历史纪要大规模补填使用原管理台批量功能，不自动发起高额全量复盘。正常拍保存事实后调用原插件 `triggerUpdate`，写完整的原插件V2帧并生成世界书；源收据为 `rp-database-memory`。

失败标pending，不假称入库成功；下一拍先恢复旧source，再准备新记忆。已保存同source帧去重，不重演故事。取消关闭在途浏览器任务；切卡/分支丢弃迟到写入。手动资料落插件派生书，不混入自动故事事实，生成表行需从原管理台管理。

## 管理与更新

设置→上游数据库插件：启用/回退旧后端、原管理台、固定源码安装、检查更新和回退上一版本。检查更新只看已知仓库，验证Git对象与CDN字节，再生成commit固定地址和SHA-256；不自动激活不明新版本。安装成功保留前一指针；失败不覆盖有效缓存。上游候选升级仍需隔离验收，不声称版本永远兼容。

首次加载会为宿主配置独立记忆模式：有云端嵌入时交火、否则经典表格；0TK开启，独立剧情代写关闭。上游可能按它自己的迁移规则刷新召回默认值，不能把宿主初值冒称固定上游默认。两千纪要浏览器回归已覆盖真实填表、持久化、世界书投送、交火嵌入代理、0TK目录关闭、同source恢复去重与兄弟隔离；模型/嵌入是合成响应，不等于真实千楼文学答对率。

## 运行依赖

服务端用Playwright运行原浏览器插件，不要求用户一直开着网页；Chromium及其运行库需要部署者安装。可设置 `LIYUAN_DATABASE_BROWSER_EXECUTABLE` 和 `LIYUAN_DATABASE_BROWSER_LIBS`。浏览器只允许同源宿主请求，外部模型由服务端代理。首次安装的jQuery3.7.1与sql.js1.14.1私有依赖缓存由维护流程核验；不把它们或插件字节当本项目源码发布。

测试命令：`npm run test:database-plugin`；`npm run test:database-plugin-browser`需要显式合成缓存路径，未提供时只报跳过，不假冒端到端成功。完整离线门禁仍为 `npm run verify`，不等于真实模型、全后端tsc或三平台发行。
