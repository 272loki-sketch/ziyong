# 导演室：讨论、提案、研究与只读诊断

导演室是独立创作工作台，不等于每拍director模式。它不代替主Agent写正文，也不把候选建议变成事实。

## 入口和用途

主输入旁、欢迎页和面板入口可打开；桌面宽弹窗/全屏，移动端全屏。用于创作对谈、提案审阅、故事脉络、人物/伏笔、藏书消化、研究、素材以及演出回放。

讨论按任务关注下一拍、对白、人物、节奏、日常机制或长期方向；用户原始写法与已提交事实优先，不另加默认主角权限/停点。讨论写 `rp-outline-chat`，清空讨论不删除正文或大纲。

## 大纲提案

manual/suggest/auto按明确设置运行，version/hash和来源保护生效；高风险变更需要确认，自动只提交审计允许的低风险更新。提案未确认不是当前故事，见 `PLAN-OUTLINE-SYSTEM.md`。

## 本拍诊断

当前direct/director流程、专家状态、正文首字/完整耗时、实际请求、角色账本、启用世界/生态、格式/恢复、记忆和大纲旁路各按安全工件记录。不能把旧逐段稿纸流水线当成当前执行，也不能把并行阶段耗时简单相加。

成功、降级、失败、跳过、复用、pending/待确认分别显示；历史缺少工件时说明不可用，不伪造调用。只读诊断不改正文/分支，不公开完整thinking或专家私有报告。

## 小说素材

长文与Kakuyomu消化在背景，预算/进度/暂停恢复可见；研究素材有出处定位，不把原著候选覆盖当前分支。Novel Play确认开场另有作品版本门禁，见 `PLAN-NOVEL-DIGEST.md`、`NOVEL-PLAY.md`。

系统助手另负责配置/运维工具，拥有独立会话；导演室/助手都不是第二正文作者。当前正文模式见 `GENERATION-MODES.md`，记录阅读与恢复见 `RECOVERY-AND-DIAGNOSTICS.md`。
