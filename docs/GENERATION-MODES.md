# 两种正文生成模式

适用现行Web和本地v1.8.10，模式绑定输入而非当下按钮状态。只有主Agent写正文，报告与候选不成为事实。

## 直出 direct

原始启用资料/当前分支/已有记忆与世界生态 → **正常文学导演** → 单主Agent普通文本 → 共用结算和完整卡格式。

原 `literaryDirector` Skill职责保留，不把直出缩水成裸一发API。直出不新生成拍前生态，不跑心理画像、多角度团队审稿。

## 导演 director

同一主Agent主持固定流程：三份证据报告（连续性、设定知情、生活生态）→ 两个角度 → 主Agent起草 → 事实/原始预设两份审阅 → keep或主Agent修改 → finalize → 共用结算/完整格式。

每拍相同岗位，报告可以没有意见。专家只得真实送达材料、有界历史和前阶段报告；原预设和待审稿按岗位完整送达，不传全主Agentthinking、不允许专家代写或定稿。

## 交互与权限

输入框/设置可选择直出或导演，默认导演。排队、断线重放和重Roll保留提交模式。剧情不进入旧ask停点；工具/MCP真实风险授权仍保留。

阶段转换需读取回执，每次生成最多一次阶段转换。工具可用性只影响对应原生/文本协议，不把导演偷换成直出。主Agent的资料/面板写操作在正文保存结算后执行，取消不写。

## 保存、格式与恢复

主作者原交付保留于 `rpAuthorDraft`；事实正文为 `rpNarrative`；展示布局引用冻结正文与原图片，绑定同一正文id。主作者格式合同来自启用原文，不做固定面板白名单或复活关闭模块。

正文已保存而领域/格式未完成时留下pending收据；下一拍前恢复，不重写故事或重复已完成结算。中断半稿不会按普通成功拍入记忆。

## 预算和分工

direct/director默认30/60分钟整拍，作者默认8/24轮，单流15分钟保护；触限保留未完成而非自动成功。世界、生态、记忆、摘要、研究、格式等各有调用/预算。

模型岗位独立。3.7/3.8 Flash保留原分工；Luna6是独立选项，不代替所有岗位。详见 `MODEL-CONNECTIONS.md`。

实现入口：`src/stage/engine.ts`、`agent-turn.ts`、`agent-director.ts`、`agent-presentation.ts`。执行合同见 `PLAN-ROUND-FLOW.md`，权限 `PLAN-RP-TOOLING.md`，记忆 `PLAN-RP-MEMORY.md`。
