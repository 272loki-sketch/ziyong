# 2026-10-03 稳定性迭代与验收计划

> 状态：v1.7.3 代码集成、离线验收与当前 VPS 部署完成。本文记录用户授权范围、取舍与验收，不替代架构和流程权威文档。
> 当前用户卡片可信，本轮不更改 HTML iframe、CSP 或程序卡的脚本行为。

## 不变的边界

- 正文仍由 StageEngine 唯一拥有，事实和分支仍以 Session Tree 为准。
- 文学语义规则进入 Skill；TypeScript 只负责来源校验、编排和确定性门禁。
- 保留本轮开始前的未提交改动，不重置、提交、升级依赖或操作线上服务。
- writer 输入预检只做容量估算与诊断，不解析正文格式，不静默删除正文、历史或规则。
- 用户 Skill 覆盖不得被版本更新或提示操作自动覆写。

## 交付与验收

| 范围 | 最小交付 | 关键验收 |
| --- | --- | --- |
| WS 权限撤销 | 凭据撤销与既有连接权限一致 | 改密、注销后的旧连接不能命令或接收广播 |
| 可靠消息提交 | 会话绑定、请求 ID、确认与可恢复待发送消息 | 断线/刷新不无提示丢稿；换会话不投错；重发不重复落树；状态命令不自动重放 |
| 记忆删除一致性 | 删除/清空/删库与在途写入协调 | 延迟 embedding 返回后已删除数据仍不存在；删除成功与实际完成一致 |
| 小说消化 | 全阶段暂停/删除门禁、持久化真实调用预算 | reduce/extract 暂停不继续推进；恢复可接力；重试/并发/重启不重置或突破预算 |
| 回合元数据 | 保留正文 sibling 结构及活动路径设置 | 思考档变更完成后重载不恢复旧值；纯设置变更不丢场记；真正切支仍拒旧提交 |
| 发布包 | 一致排除用户覆盖和数据 | 隔离 marker fixture 不进入 ZIP；产品扩展代码仍保留 |
| 输入预检与性能 | 非破坏性容量提示、分阶段只读指标 | 输入内容原样保留；首次正文和拍后耗时可区分；跨拍后台任务不串指标 |
| 生态用户承诺 | 新承诺有当拍用户来源证据 | 缺证据不能将 optional 升为 committed；既有承诺保留；引用校验不冒充完整语义证明 |
| Skill 更新提示 | 覆盖基线指纹、过期/未知提醒和内置对照 | 内置变化触发提醒；旧覆盖无基线不误判；确认只更新元数据不覆盖用户正文 |
