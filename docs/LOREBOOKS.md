# 世界书：卡内书、独立书与补充设定

当前角色卡内 `character_book` 自动随卡加载；世界书面板默认展示当前卡内书，全部启用/停用条目可全文过滤、展开和编辑，无需复制或重复挂载。

绿灯常驻、蓝灯关键词、灰灯停用。独立书可多本勾选挂载；卸下独立书不关闭卡内书。agent补充按卡加载，新增内容可写补充设定；卡内新增尚未提供面板入口。

条目管理明确 `source=card|file|agent`。独立书限定已知path，卡/补充绑定当前cardIdentity；同本重复正文用原始entryKey。指纹不再横扫所有书写入，切卡/修订旧请求拒绝。

显式启停写原生enabled/disable，旧全局停用仅按所选来源/行豁免，不误开另一书或其他默认关闭模块。批量先校验所有目标再保存，需二次确认；文件/配置同步保存失败尝试原字节回滚。

卡内保存原子替换、保权限和软链接；双ccv3/chara的内嵌规范状态同步，保立绘与各自未知字段。源内容/卡字段不作为修复测试材料；生产只读，回归用合成JSON/PNG。

导出当前卡包括停用项，导出合并包括卡内/挂载/补充并沿原优先级去重。卡切换和编辑失效缓存，旧慢GET不能回填新卡。

验证 `lorebook-panel-rest.test.ts`、`lorebook-cache.test.ts`、`web/test/lorebook-panel.test.mjs`。
