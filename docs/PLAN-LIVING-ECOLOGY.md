# 当前鲜活世界生态

生态提供镜头外生活和自然候选，不是第二正文或新的事实权威。

## 三层

1. 全局叙事原型池：可复用生活/场所/事件机制。
2. 卡级生态池：依据原始人物/作品/地区资料生成的适配候选。
3. 分支生态运行态：本分支人物生活、场所、事件、通讯、认知与传播状态。

## 双模式

直出读取已有池和生态的只读投影，不新生成拍前arrival；导演模式的生态专家也读取真实已有资料。后台搜索/双池备料为后续拍服务，不把待生成候选当当前事实。

后台备料分running/ready，单条运行链、串行写入，写前重读最新池并合并useCount。ready才消费，不等待未完成的背景池阻塞正文首字。

## 拍后与认知

保存正文后的after-math依据宿主绑定的sourceRefs/原文片段处理人物、事件、场所和信息传播；候选、未保存草稿、专家建议不能成为committed依据。家庭/势力/地域认知边界和传播链要校验，不把全知后台信息给角色。

世界转移与生态可并行计算，但按既定顺序落树；取消/切支拒绝迟到结果。失败保留真实状态并有明确降级，而不是伪造完整生态。

启用/搜索和模型插头是独立设置，不因模式或Luna改名改变Flash岗位。入口 `src/stage/literary-ecology.ts`、`passive-ecology.ts`；测试 `literary-ecology.test.ts`、`ecology-narrative-commitment.test.ts`。
