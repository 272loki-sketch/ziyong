# 当前小说长文消化与研究素材

这是导演室背景资料管道，不创建新的正文作者或Session。

## 输入与结果

上传文本/文档 → 解码、清洗、分章、分块 → 有界模型消化 → 文档摘要/机制资产/可复核定位。Kakuyomu作品页入口和分类自动发现已实现；通用任意目录页URL抓取未实现，不能把平台支持泛称所有网站支持。

文档/块状态有pending/running/paused/ready/error等进度，检查点落盘，失败可按任务恢复。原始作品来源、章节与块范围保留；机制只能引用引擎生成的evidence index，不能模型自报出处。

## 执行

正文关键路径之外，文档级有界并行；同一任务块处理和写状态串行。显式预算、最大调用数、暂停/删除、取消与恢复都有门禁；后台运行时不能因前台刷新重复生成。

默认自动发现关闭。用户显式开启后，按其计划和预算挑选资料；手动“自动选书”不是开启所有未来定时收费。自定义岗位与既有研究插头按配置解析，不能无提示回落昂贵模型或启用旧保存渠道。

## 使用

研究/导演/世界适配只取与任务匹配的机制和证据；不把整部小说原文加入主演上下文。ready表示管道工件生成成功，不证明研究内容绝对正确。Novel Play另以不可变包、原文锚点和开演确认复用这些资料。

入口 `src/outline/corpus.ts`、`kakuyomu.ts`、`research.ts`、`server/rest.ts`；操作界面为导演室小说资料区。测试小说解析、断点、预算、暂停/恢复/删除、失效源和来源定位。通用网站抓取/任意书城搜索仍不在现实现范围。
