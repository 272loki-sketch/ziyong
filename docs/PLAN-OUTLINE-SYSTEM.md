# 当前导演室与长期大纲

导演室是独立讨论、研究和提案工作台，不等同于每拍的director正文模式，也不插入旧剧情停点。

## 状态

大纲 `rp-outline` 按当前分支祖先链读取，保存revision/hash。提案、讨论和未来节点不是已发生正文事实。用户确认和自动低风险提交都有基线版本/来源校验，过期提案不能覆盖新状态。

## 模式

- manual：用户讨论/提案，不在正文拍后自动校准。
- suggest：拍后旁路校准可提出建议，不直接改高风险方向。
- auto：只允许审计通过的低风险自动更新；高风险修改仍须用户确认。

研究开关off/manual/auto与大纲模式独立；预设、原著材料和角色事实高于无出处研究猜测。请求采用已配置岗位，失败不会自动借用私人仓库渠道。

## 小说与证据

CorpusEngine、Kakuyomu资料和Novel Play提供带定位的研究材料/不可变作品包，不能把原著候选写成当前分支事实。Novel Play开场提案确认属于作品开演事务，不是正常正文每个剧情动作需要确认。

入口 `src/outline/engine.ts`、`schema.ts`、`validation.ts`、`research.ts`、`corpus.ts`，Web `web/src/planning/`。验证提案版本、自动高风险拒绝、来源和分支隔离。
