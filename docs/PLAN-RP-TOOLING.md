# 当前统一工具与权限边界

`src/tools/` 定义同一领域工具契约，adapters按台上/系统助手能力投影。普通文本主Agent使用阶段工具与领域工具，专家只返回报告。

## 主Agent

检索/来源核对/记忆/媒体与已授权外设；导演模式通过固定阶段协调工具主持3/2/2报告、审稿和定稿。一次生成只受理一次阶段转换，须消费回执后继续。

不再提供剧情 `ask`、逐段稿纸写作门禁或让专家直接改稿。资料/面板写操作延后到正文保存与结算之后，取消拍不执行。

## 系统助手

独立会话与能力集合；诊断、配置、导入和外部服务不是另一位正文作者。现实付款、删除、发帖等权限不等于故事行为。

## 各领域安全

- 世界书：卡内/独立/补充来源分开，管理写回带来源/身份/行键。agent补充不篡改原卡。
- 记忆：宿主绑定session/card/可见祖先来源。手工写额外库；周期与证据由宿主写剧情库。
- 账本/世界/生态：本拍明确输入和已保存正文是提交证据；候选不成为已发生事实。
- 研究与导演室：原文/locator可追溯，提案与确认另有事务门禁。
- 本机/MCP：能力和实际授权检查保留，不为剧情选择恢复授权弹窗。

代码入口：`src/tools/registry.ts`、`src/tools/adapters/stage.ts`、`src/stage/tools.ts`及各领域服务。错误、无权限和不支持原生tools分别诊断，不把schema错误或网络524说成“不支持工具”。
