# 当前预设、工作流Skill与格式材料边界

预设保持用户原文和装配语义，不沿用旧实验的强制拆层、统一文风黑名单或逐段写法。

- 写法/人物/视角/长度/展示需求由原始启用预设、角色卡和世界书决定。
- 系统Skill负责岗位、工具、阶段和交付协议；不能借流程规则改写用户预设。
- 关闭模块不因皮肤正则或关键词猜测重新启用。显示正则不是独立的生成要求。
- 外部插件强制协议与梨园实际支持能力分别处理；协议退场门禁保留，不等于删除所有作者格式。
- 采样参数作为参数投影，不用另一套提示词重复署名。

编辑保存/工作草稿遵循当前预设REST合同；用户Skill覆盖不随版本被内置Skill替换。格式事实与布局分离，详见 `FORMAT-DELIVERY.md`；来源/适配信用见 `PROMPT-SOURCES.md`。
