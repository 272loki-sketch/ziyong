# 当前请求预算与资料分工

预算是执行/费用边界，不是写作风格要求。

## 预算

- 整拍默认 direct 30分钟、director 60分钟，可明确配置覆盖。
- 普通作者默认最多8/24轮；单writer流15分钟硬上限。截止保留未完成收据，不静默定稿。
- 专家固定3证据、2角度、2审阅，每阶段有界并行，单岗位失败不伪装为成功；不可用与语义校验失败分开。
- 普通分析/研究、记忆事件、世界、生态、摘要、格式交付有各自预算和有限重试，不能把7岗位称为整拍全部API次数。
- 代理首包或空闲限制与整拍预算不同；延长总预算不能修复传输无心跳。连接边界见 `MODEL-CONNECTIONS.md`。

## 发送材料

主Agent读原始启用预设、卡/人设、常驻/命中世界书、分支历史/摘要、现有记忆和状态、启用世界/生态及导演室资料。原始预设不转成一套新风格规矩。

专家只接本岗位所需来源、有界历史/状态、前阶段短报告；审阅保留完整待审稿和原始预设。专家不接全主Agent思考，不把他人的报告变为原始证据。

后端容量预检只观测和提示，不静默截断用户正文或预设；未知模型容量不能硬判。只能核验实际送达来源id，不能让裁掉的资料通过引用验证。

未实现完整自动token成本优化和跨供应商TPM治理，不宣称未知模型的真实reasoning用量受到全部硬限。
