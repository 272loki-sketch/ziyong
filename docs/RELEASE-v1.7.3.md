# 梨园 v1.7.3 稳定版

日期：2026-10-03

## 本版重点与修复

- **消息与权限恢复**：WebSocket 权限撤销后立即作用于既有连接；用户消息按会话和请求 ID 确认，断线重连可恢复未确认草稿并避免重复落树。已发出但未确认的助手请求保留为恢复草稿，不自动重放。
- **记忆删除一致性**：同一进程内协调删除、清空、删库与在途写入，避免延迟写入复活已删除内容。
- **小说消化生命周期**：暂停、删除门禁覆盖异步处理阶段，并持久化实际模型调用预算，降低恢复、重试或并发时越过预算的风险。
- **非破坏性容量预检与指标**：对可识别的主演上下文容量给出提示，不截断或改写输入；分阶段记录只读耗时指标，可区分首次正文与后续阶段。
- **生态承诺证据**：新承诺须关联当拍用户来源及事件证据；来源校验不等同于完整语义证明。
- **Skill 更新提醒**：根据覆盖基线提示过期或未知状态；显式核对只更新基线元数据，不覆盖用户正文。
- **前端版本与缓存**：界面 banner 比较实际前端构建版本和服务端 hello 版本；Service Worker 缓存按构建版本隔离并更新。

## 已知边界

- 记忆写入锁是**单进程**协调，不覆盖多个进程共同操作同一数据的情形。
- 助手请求断线后以恢复草稿供用户检查和手动重试；不承诺模型执行 exactly-once。生态证据绑定也不宣称完整 semantic proof。
- 需要 Node.js `>=22.19.0`；本版未升级依赖版本。
