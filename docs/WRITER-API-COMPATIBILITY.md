# 当前生成API兼容与错误处理

协议与预算详见 `MODEL-CONNECTIONS.md`、`PROMPT-BUDGETS.md`。本文件不把修复前失败记录当今天的状态。

- 相同原始启用资料与格式合同适用于direct/director，正文只有主Agent。
- 只有显式supportsTools=false或供应商明确拒绝工具，才采用该模式既有文本流程；不得因524、schema错、tool_choice/reasoning组合或伪协议就宣称不支持tools。
- 专家返回结构化报告时正常不附业务工具，不叫“工具降级”。报告必须核对真实送达来源，格式校验失败与HTTP失败分开。
- 流式/非流式按该模型配置处理，不无条件强制非流式；主Agent必须读工具回执后继续。
- CLI Proxy首字前/流中15秒心跳已实测135秒完整响应，Luna6原生工具可用；保活字节不应成为正文或事实。
- 已提交响应头后的迟到失败用JSON/SSE错误体识别，不把HTTP200等同调用成功。取消、源失效、未完成稿件不会静默定稿。
- 老供应商故障、旧模型名称和旧对照恢复属于历史证据，已移出活动流程；不启用过期渠道回避失败。
