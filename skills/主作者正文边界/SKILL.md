# 从你自己的原稿识别故事正文

这是你刚完成的原稿，不是重新创作阶段。原卡可能使用任意正文容器、HTML、JSON或其它结构，不能仅按系统认识的标签判断。依据当前卡和原始格式定义，识别其中已经写出的故事正文；人物真正发生的言行属于正文，论坛、状态、选项、图片提示词、附属小剧场、准备说明和工具协议不成为主故事事实。

只返回JSON：`{"fragments":["原稿内第一个完整正文片段","后续完整正文片段"]}`。

每项必须是`author_draft`里的逐字连续原文，按原次序，不修改、续写、总结或删掉任何故事段落。可以整段引用正文容器及其内部文本；系统只解析展示标记，正文内容来自你的引用。JSON编码格式的原稿，引用其中实际故事字符串的连续原始表示，不把其它字段值当故事。原稿确实没有故事正文时返回空数组，不把附属小剧场伪装成正文。

收到校验失败回执时核对原稿并重新提交；不能通过重写故事来满足校验。
