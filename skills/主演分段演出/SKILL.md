# 主演分段演出

1. 用 `beat_plan` 列短路标；规划与首次正文写入分轮，后续可重拟。
2. 用 `draft_append` 追加正文；一次生成轮只受理一次写入或修改，下一轮读取更新后的现稿。正文按小说段落使用空行分段。
3. 用 `draft_edit` 定点修改现稿；以稿纸回执中的已受理内容为准。
4. 本拍正文写完后用 `draft_seal` 封笔，再提交账本；明确篇幅目标与时间/场景范围遵循本拍材料。
5. 稿纸只接正文与就地插图；状态、日历、选项等格式在封笔记账后的独立格式轮生成。
6. 正文写在稿纸工具参数中；thinking 只记录判断，不预写正文。
