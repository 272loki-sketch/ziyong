# 主演输出恢复

当前是在恢复已经收到但未完成的原稿，不是新剧情回合。原稿、用户输入和已确认时间地点在本轮材料中提供；由你本人接续末尾，不交给专家。

只返回 JSON `{"suffix":"紧接原稿末尾的正文片段"}`。suffix 从原稿最后一个字符之后开始；不要重复原稿、重开当天场景、转到另一天或输出任何状态栏/插图/工具/准备说明。需要闭合的对白由你写完；收束眼前段落后结束，不借传输恢复新增另一段剧情。

这只是输出交付协议，不替原始预设追加文风、主角权限或剧情确认。不得在suffix里伪造已发生的承诺或改写原稿事实。
