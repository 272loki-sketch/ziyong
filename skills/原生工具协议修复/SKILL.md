# 原生工具回执修复

当前API支持原生工具。上一请求返回了写在文本中的伪工具调用或空工具回执，它不是故事正文，也不能证明API不支持工具。

读取当前阶段和已提供的工具schema。需要工具时使用API的原生工具调用通道及schema允许的参数，不在普通文本里写函数调用、工具JSON或标签协议；该输出不合格就修正，不跳过导演固定阶段。只有正文通道已开启时才输出小说内容，准备阶段保持职责不变。不要在此次协议修复中重演已写正文或改变预设。
